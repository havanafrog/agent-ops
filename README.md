# agent-ops

한 Claude 세션이 만들고, 다른 세션이 잽니다.

두 세션은 컨텍스트를 공유하지 않습니다. **공유하지 않는 것이 핵심입니다** —
같은 맥락을 가진 둘은 같은 실수를 합니다. 자기가 짠 코드를 자기가 검토하면
"돌아갑니다"라고 쓰고 넘어갑니다. 다른 창은 그냥 돌려 봅니다.

주고받는 것은 장부 파일 하나(`.ops/ledger.jsonl`)입니다. 메시지는 컨텍스트와
함께 죽지만 장부는 남습니다.

## 까는 법

```
/plugin marketplace add havanafrog/agent-ops
/plugin install agent-ops
```

Node 18 이상이면 됩니다. 다른 의존성은 없습니다 — `package.json` 도 없습니다.

## 쓰는 법

만드는 쪽이 주장을 올립니다. 주장에는 **어떻게 확인하는지**가 반드시 붙습니다.

```
/ops claim "라벨러 정확도가 56% 나온다" --how "node tools/eval.mjs --n 240"
```

재는 쪽이 그걸 직접 돌려 보고 판정합니다.

```
/ops verify
```

| 명령 | 하는 일 |
|---|---|
| `/ops claim "..." --how "..."` | 주장을 장부에 올린다 |
| `/ops verify` | 재는 쪽으로 붙는다. 열린 주장을 직접 돌려 본다 |
| `/ops status` | 지금 뭐가 열려 있나 |
| `/ops send` | 방금 끝난 것을 다른 창에 이어서 넘긴다 |

판정은 셋뿐입니다: **확인** · **반박** · **보류**. 재는 쪽은 코드를 고치지
않습니다 — 고치기 시작하면 만드는 쪽이 되고, 그러면 잴 사람이 없어집니다.

## 딸려 오는 훅 둘

| 훅 | 하는 일 |
|---|---|
| `Stop` | 장부에 올린 것을 상대에게 안 넘겼으면 턴을 못 끝내게 막는다. 한 줄에 한 번만 막으므로 갇히지 않는다 |
| `UserPromptSubmit` | 옆 창이 방금 무슨 말을 받았는지 이 대화에 넣어 준다. 판을 안 띄워도 창끼리 뭘 하는지 안다 |

장부가 비어 있으면 둘 다 아무 일도 안 합니다.

## 판 (선택)

창들이 지금 뭘 하고 있는지 보는 화면입니다. **일하는 저장소 안에서** 띄우세요 —
거기를 기준으로 기록과 장부를 찾습니다.

```
node "$CLAUDE_PLUGIN_ROOT/ops/board.mjs"
```

http://127.0.0.1:8730 · 탭이 셋입니다.

| 탭 | 무엇 | 어디서 읽나 |
|---|---|---|
| 창 | 이 저장소 세션. 최근 다섯 수가 시간순으로 붙는다 | 기록(`jsonl`) |
| 열린 창 | 지금 이 기계에 열린 Claude Code 전부. 다른 저장소 것도 나온다 | 등록부(`~/.claude/sessions`) |
| 장부 | 주장과 판정 | `.ops/ledger.jsonl` |

**127.0.0.1 에만 겁니다.** 기록에는 대화가 통째로 들어 있습니다. 밖으로 열지
마세요.

카드를 누르면 그 창이 앞으로 옵니다. 꺼진 창이면 `claude --resume` 으로
되살립니다. 그러려면 도우미가 하나 더 떠 있어야 합니다 — 브라우저는 프로그램을
못 띄우기 때문입니다.

```
node "$CLAUDE_PLUGIN_ROOT/ops/focus.mjs"
```

윈도우 전용입니다. 창을 pid 로는 못 찾습니다 — 재 보니 `claude.exe` 도 그 부모
`cmd.exe` 도 `MainWindowHandle` 이 0 이고, 진짜 창은 Windows Terminal 하나가
전부 갖고 있어 세 세션이 같은 pid 를 가리킵니다. 남는 단서는 창 제목뿐이라
**이름을 붙인 창만** 눌러서 찾을 수 있습니다.

## 파일이 어디 생기나

일하는 저장소 안 `.ops/` 입니다. 플러그인 폴더가 아닙니다 — 거기 두면 저장소
열 개가 장부 하나를 같이 쓰게 되고, 다른 일의 주장이 섞이면 판정이 아무 뜻도
없어집니다.

```
<저장소>/.ops/ledger.jsonl    주장과 판정
<저장소>/.ops/handoff.json    넘길 게 남았나
<저장소>/.ops/whoasked.json   창마다 마지막으로 받은 말
```

`.gitignore` 에 `.ops/` 를 넣으세요. 남기고 싶으면 장부만 빼고 넣으면 됩니다.

## 점검

각 파일이 자기 점검을 갖고 있습니다. 프레임워크는 안 씁니다.

```
for f in repo ledger handoff board whoasked focus; do node ops/$f.mjs --selftest; done
```
